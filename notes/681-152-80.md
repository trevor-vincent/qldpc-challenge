# [[681,152,80]] — shortened cyclic generalized-bicycle CSS code

## Direction & hypothesis

The published uncapped CSS `kd²/n` record is `codes/682-142-82.json`,
scoring 1400.012. This length-681 code has k = 152, maximum check
weight 32, and a witnessed upper bound of 80. At that bound it scores
152 × 80² / 681 = 1428.488. Exact distance and literature novelty are
open.

## What was searched

The parent is a cyclic generalized-bicycle CSS code on 682 qubits,
with 341 × 341 circulants and polynomial supports

```
a = [0,1,3,16,22,27,76,132,173,198,228,243,266,273,312,324]
b = [0,3,16,66,93,105,136,140,181,186,203,233,236,252,269,282]
```

The complete parent matrices and witnesses are in
`research/evidence/681-152-css-ee0308/parent.json`. Measure Z on
parent qubit 0 (zero-based), retain X rows avoiding it, and delete
that column from both matrices. The X rank falls from 265 to 264
while the Z rank stays 265, so k = 681 − 264 − 265 = 152. The
reproduction script checks the exact rows and ranks. No lower bound
on the child's distance is inherited from the parent.

## Evidence trail

The saved parent operators project to child X85 and Z85 logicals.
An initial child screen returned Z86, X88, and X85 operators across
its general RIS stages. The projection, full screen results, and
shortening map are committed in
`research/evidence/681-152-css-ee0308/`.

An independent two-thread RIS run at pair depth 512 returned X83
after 100,000 trials and Z80 after 1,000,000 trials. Its seeds were
306020000 and 306020001. The complete raw supports and pinned request
are committed under the same evidence directory. The submitted file
uses the projected X85 and independent Z80 witnesses. Both pass direct
logical validation on the submitted checks.

The unchanged structural verifier accepts the file. The unchanged
candidate validator passed at seed 310308080 against clean board
commit `c76dbbc3`, finding no lighter logical in its 8,000-trial
refutation, no exact or WL-equivalent board entry, and no dominating
CSS code. Its verdict is
`research/evidence/681-152-css-ee0308/validator-verdict.json`.
The same unchanged gate also passed at seed 310308180 against rebuilt
board commit `bb2fd482`; the second verdict is
`research/evidence/681-152-css-ee0308/validator-verdict-main-bb2fd482.json`.
The claim is **d ≤ 80**, not exact distance. Independent GPU job
59717487 is auditing the bound.
