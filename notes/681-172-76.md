The published uncapped CSS `kd²/n` record is `codes/682-142-82.json`,
scoring 1400.012. This length-681 code has k = 172, maximum check
weight 32, and a witnessed upper bound of 76. At that bound it scores
172 × 76² / 681 = 1458.843. Exact distance and literature novelty are
open.

`research/evidence/681-172-css-ar8617/parent.json`. Measure X on
parent qubit 0 (zero-based), retain Z rows avoiding it, and delete
that column from both matrices. The X rank stays 255 while the Z rank
falls from 255 to 254, so k = 681 − 255 − 254 = 172. The reproduction
script checks the exact rows and ranks. No lower bound on the child's
distance is inherited from the parent.
