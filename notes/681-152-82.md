# [[681,152,82]] — single-qubit shortening of a cyclic CSS code

## Direction & hypothesis

The uncapped CSS `kd²/n` record on the comparison board is
`codes/682-142-82.json`, scoring 1400.012 at maximum check weight 32.
This length-681 code has k = 152, maximum check weight 32, and the
witnessed upper bound d ≤ 82. At that bound its score is
152 × 82² / 681 = 1500.805. A bound of 80 would still score 1428.488.
Exact distance and literature novelty are open.

## What was searched

The parent is a cyclic generalized-bicycle CSS code on 682 qubits. Its
complete checks and validated witnesses are in
`research/evidence/681-152-css-sc0121/parent.json`. The defining
polynomial supports are:

```
a = [0,1,2,13,27,38,49,91,93,110,159,197,211,236,247,252]
b = [0,1,13,17,22,27,28,43,68,72,110,154,178,257,264,323]
```

Let C(S) be the 341 × 341 circulant with row i supported on
`(i+s) mod 341` for s in S. Build the parent as
`H_X = [C(a) | C(b)]` and `H_Z = [C(b)^T | C(a)^T]`.
Measure Z on parent qubit 12 (zero-based), discard X rows touching
that qubit, and delete its column from both matrices. The retained
X rank is 264 and Z rank is 265, giving k = 681 − 264 − 265 = 152.
The exact row selection and column mapping are in
`research/evidence/681-152-css-sc0121/shortening.json`.

The parent has only a witnessed distance upper bound, so no distance
lower bound is inherited by shortening. The child was searched and
validated independently.

## Evidence trail

The initial child witnesses projected from the parent had weights
85 on X and 84 on Z. Four general RIS calls totaling 610,000
requested trials at pair depth 32 returned no operator lighter
than 84. Their raw supports are committed as the `general0` through
`general3` witness files in
`research/evidence/681-152-css-sc0121/`.

A later saved parent operator projected to a valid child Z logical of
weight 82. Its complete support and parent mapping are in
`research/evidence/681-152-css-sc0121/saved-parent-projection.json`.
The submitted file carries that Z witness and a separately validated
X witness of weight 85. The unchanged structural verifier accepts
both. The unchanged candidate validator passed on the submitted bytes
against a clean board at commit `8c2db059`, seed 201281325; it found
no exact or WL-equivalent entry and no dominating CSS code. Its result
is `research/evidence/681-152-css-sc0121/validator-verdict.json`.

The claimed distance is **d ≤ 82**, an upper bound. A deeper GPU
refutation and an independent million-trial CPU search are underway.

## Dead ends

The earlier draft bound of 84 was withdrawn when the weight-82
projection was found. That draft was not submitted. The present file
uses the corrected witness. The parent itself had tentative bounds
105, 92, 88, and 86 before a weight-85 operator was found; those
records are in `research/evidence/681-152-css-sc0121/search-history.json`.

## Reproduction

The reproduction script rebuilds the parent and child checks, matches
the submitted matrices, and validates 18 retained parent and 10 child
witness records:

```sh
uv run --extra research python research/evidence/681-152-css-sc0121/reproduce.py
uv run python verify/qldpc_verify.py codes/681-152-82.json
```

The parent construction sample replay can be requested with
`--replay-construction <output-directory>` on `reproduce.py` after
building the repository's native extension.
