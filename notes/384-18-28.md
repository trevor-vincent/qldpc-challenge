## Direction & hypothesis

Target cell: weight-9plus x unrestricted (CSS), which is where the verifier
places a check weight of 9. The source is arXiv:2608.08996 Table 1, published
at n = 384, k = 18, w = 9 with a QDistEvol upper bound of 28 and Q = 36.75. No
board entry shares (n, k) = (384, 18) and nothing dominates it at n <= 384, k

codes in that table this one is the highest-Q candidate that had not already
been mined, and it is the last of them I could reproduce: [[390,36,<=30]] and
[[384,32,16]] from the same table do not reproduce, and [[400,16,<=22]]

## What was searched

No search for the construction. It reproduces from the paper's Supplementary
Information, which sits at the end of main.tex after the References and so is
invisible to a text search of the article body. G = SL(2,3) rtimes_phi Z_16
with the action y M y^-1 = P M P^-1 for P = [[1,1],[2,1]] in GL(2,3), and K =
<-I>, verified normal in the constructed group rather than assumed --
conjugation by any matrix fixes a scalar, and phi(-I) = -I. K has order 2 so
the quotient has order 192, and with 1x1/1x1 boundary maps n = 2|G/K| = 384.
Every invariant matches the paper: n = 384, k = 18 by GF(2) rank, w = 9, H_X
H_Z^T = 0 over GF(2), and d = 28 on both sides, so the published bound is
tight.

## Dead ends

- [[390,36,<=30]] from the same table does not reproduce: n, w and CSS
  commutation all hold but both check matrices come out full rank and k = 0,
  against a published k = 36.
- [[384,32,16]] does not reproduce: n = 384, k = 32, w = 8 and CSS all match,
  but the paper claims an EXACT distance of 16 and the build gives 8, so the
  2x2 protograph orientation over S_3 x Z_8 could not be pinned.
- [[400,16,<=22]] reproduces structurally (n = 400, k = 16, w = 6) but the
  true distance is at most 12, at which six entries dominate it, so it does
  not advance the board.
- The first attempt at this construction failed an assertion that K = <-I> is
  not normal. That assertion was wrong, not the group: -I is scalar so it
  commutes with everything, and phi(-I) = -I. The bug was computing the
  inverse map as mul[g, 0], which is g itself rather than g^-1.

## Reproduction

uv run python; enumerate SL(2,3) as the 24 matrices over F_3 of determinant 1
with the identity at index 0, form the semidirect product with Z_16 via
(M,z)(M',z') = (M phi^z(M'), z+z') with phi(M) = P M P^-1 and P =
[[1,1],[2,1]], take the coset quotient by K = <-I>, and call
research/kit/group_algebra.build_2bga on the quotient Cayley table with A = e
+ [[1,1],[1,2]]y + [[1,0],[1,1]]y^3 + [[1,1],[0,1]]y^3 + [[0,1],[2,0]]y^6 and
B = e + [[1,2],[0,1]]y + [[1,0],[1,1]]y^2 + [[0,1],[2,0]]y^5 as element
indices. Returns (H_X, H_Z) on n = 384 with check weight 9.
