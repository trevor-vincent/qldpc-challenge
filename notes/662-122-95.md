# [[662,122,95]] repaired two-qubit Clifford image of a cyclic GB code

This stabilizer code encodes 122 qubits in 662, has maximum generator weight 32, and carries a **witnessed Pauli upper bound, d ≤ 95**. It is a disclosed two-qubit Clifford image of the supplied CSS parent. It belongs to the separate unrestricted, weight-9plus stabilizer board. No exact-distance or literature-novelty claim is made.

At its witnessed bound, its raw kd²/n score is 1663.2175226586103. The comparison snapshot is unitaryfoundation/qldpc-challenge commit `6103818d2b641ed80185a89f790ad70491f8db7d`, whose highest raw stabilizer score is 82.43362831858407 for [[452,115,18]]. The values and source hashes are in `research/evidence/662-122-95-repaired/board-comparison.json`. These are comparisons of retained upper bounds, not distance lower bounds or live acceptance.

## Direction & hypothesis

The parent is a cyclic generalized-bicycle CSS construction on Z_331, with H_X=(A|B), H_Z=(Bᵀ|Aᵀ), n=662, k=122, maximum check weight 24, and retained witnesses of weight 80. Its exact polynomials and the 108 selected pairs (q,331+q) are in `research/evidence/662-122-95-repaired/construction.json`; its complete checks and witnesses are in `research/evidence/662-122-95-repaired/parent-css80.json`.

Each selected pair maps X1→Z1Y2, X2→Y1Z2, Z1→Z1X2, and Z2→X1Z2. This preserves the symplectic form, n, and k. Pure-X and pure-Z logicals gain one unit of weight per singly occupied pair; Y-only logicals preserve their weight. The aim was to raise the weights of short parent logicals while keeping every generator at weight 32 or below.

The supplied parent is not asserted to be the snapshot's other n=662, k=122 entry. That entry has different checks; the saved fixed-label row-space and witness comparison is `research/evidence/662-122-95-repaired/same-parameters-board-comparison.json`. No arbitrary-permutation equivalence proof or board-parent slug is asserted.

## What was searched

An earlier mask used 112 pairs and retained a working bound of 95. New external searches of the parent supplied weight-80 logicals. Their symmetry images lowered that earlier mask to 94. The old claim is withdrawn; the corrected old code and its mask are retained under `research/evidence/662-122-95-repaired/history/old-mask-corrected94.json` and `research/evidence/662-122-95-repaired/history/old-mask-definition.json`.

The submitted mask is different. A finite binary optimization used 331 pair-selection variables and 12,578 inequalities covering check weights and saved logical images, including the new parent operators. SciPy 1.17.1/HiGHS returned a feasible 108-pair mask in about 8.4 seconds. It removed seven old pairs and added three. The reported relative optimization gap was about 6.43%; exact optimality was not proved. Its finite logical constraints do not cover unknown logicals.

The problem, returned solution and feasibility check are `research/evidence/662-122-95-repaired/pair-selection-problem.npz`, `research/evidence/662-122-95-repaired/pair-selection-solution.json`, and `research/evidence/662-122-95-repaired/pair-selection-validation.json`. The optional solver is `research/solve_pair_selection.py`; the frozen pair list suffices to reconstruct the code without optimization.

## Dead ends

The old mask's fall from 95 to 94 demonstrates that passing earlier searches, including a longer native run, did not establish its distance. The repair only incorporates known failures. The parent Y-only sector already supplies weight 95 here, so improving this construction beyond that bound requires changing the transformation or parent, not merely optimizing the same pair mask.

## Reproduction

Reconstruct the exact matrices and check both supplied code documents:

```sh
python research/reproduce_pair_clifford_662_122.py \
  --definition research/evidence/662-122-95-repaired/construction.json \
  --parent research/evidence/662-122-95-repaired/parent-css80.json \
  --candidate codes/662-122-95.json --out construction-check.json
```

Validate all indexed native returns and mapped Pauli logicals:

```sh
python research/replay_pair_clifford_search_662_122.py \
  --definition research/evidence/662-122-95-repaired/construction.json \
  --records research/evidence/662-122-95-repaired/native-searches.json \
  --out native-check.json
```

```sh

  --definition research/evidence/662-122-95-repaired/construction.json \
  --bank research/evidence/662-122-95-repaired/parent-bank.json \
  --followups research/evidence/662-122-95-repaired/empty-followups.json \
  --candidate codes/662-122-95.json --out parent-orbit-check
```

These deterministic evidence checks establish no distance lower bound.
