# [[662,122,80]] weight-24 cyclic generalized-bicycle CSS code

## Direction & hypothesis

The existing `codes/662-122-84.json` has check weight 30. The search looked
for a lighter-check construction with the same length and dimension that
could enter the CSS weight-9plus, unrestricted Pareto frontier. This code has
check weight 24. At its witnessed bound its kd^2/n is 122 x 80^2 / 662 =
1179.5, an upper-bound-based value, not a certified distance.

## What was searched

Cyclic generalized-bicycle pairs on 331 positions per block. The two
weight-12 polynomials below were retained from sparse words in a degree-61
divisor ideal of x^331 + 1; both share that divisor, which gives k = 122.
After a random-information-set screen, a 100,000-trial operator search on the
related block construction supplied a weight-80 logical and its cyclic CSS
dual, which are the submitted witnesses.

## Evidence trail

The tentative claim was 81. Two GPU random-information-set runs on
`verify/ris_gpu.py`, each with 300,000,000 trials per side, found weight 80:
seed 1 returned X weight 82 and Z weight 80, and seed 2 returned X weight 80
and Z weight 82. Both runs took the 81-claim construction as input, whose
check matrices are identical to this record's. Their operators were
CPU-verified by the search runner, and the submitted X and Z witnesses pass
the trusted structural verifier on their own. The unchanged
`verify/validate_candidate.py` passed this file on 2026-10-12 with a fresh
8,000-trial refutation seed and found no duplicate or dominating CSS entry.
The claim is d <= 80, a witness-backed upper bound; no exact distance or
literature novelty is asserted.

## Dead ends

The tentative 81 did not survive deeper search and was corrected to 80 before
submission. Another pair in the same degree-61 ideal fell to a weight-78
logical in deeper search, so this pair was kept for the weight-24 submission.
